# Security

dbscope connects to databases and stores their passwords, so security reports
are handled with priority.

## Reporting a vulnerability

Report it privately through
[GitHub's security advisories](https://github.com/ShreedharJoshi31/dbscope/security/advisories/new),
not in a public issue. Include what an attacker can do, the steps to reproduce,
and the dbscope version (`dbscope version`).

You will get a reply within a week. Please give a reasonable time for a fix
before disclosing it publicly.

## Supported versions

Fixes go into the latest release on `main`.
